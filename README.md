# CarrierSelector for iOS

Приложение для выбора, установки и проверки операторских профилей на iPhone. Основано на [CarrierSelector](https://github.com/carrierselector/CarrierSelector), интерфейс написан на SwiftUI.

**iOS 26.0+ · Sideload · LocalDevVPN + Remote Pairing · Без jailbreak**

[Скачать IPA](https://github.com/dreamw0rk/CarrierSelector-iOS/releases/latest) · [Состояние сборки](https://github.com/dreamw0rk/CarrierSelector-iOS/actions/workflows/build.yml)

## Возможности

- **Каталог профилей Apple.** Поиск по названию, версии и оператору, избранное, фильтрация по модели iPhone. Список доступен офлайн; пакеты для установки загружаются отдельно.
- **Подборка для российских операторов.** МТС, МегаФон, Билайн, T2, Yota и другие операторы. В карточках — особенности профиля и известные ограничения.
- **Текущий профиль и его версии.** Нажмите на активный пакет на экране установки, чтобы открыть точную версию или посмотреть другие выпуски в каталоге.
- **Сравнение любых двух профилей.** Доступно из каталога и карточки пакета, в том числе без подключения iPhone. Неоднозначные настройки разных плат не выдаются за известное значение.
- **Оператор по SIM.** Подборка автоматически учитывает штатный пакет SIM, если оператор определён однозначно. Ручной выбор сохраняется и не заменяется автоматически.
- **Сравнение с текущим профилем.** VoLTE, условия VoWiFi, EVS, переключатель 5G, APN и его редактирование. Сравнивается точная версия пакета из каталога для модели iPhone; отсутствующие и неоднозначные сведения выделяются отдельно.
- **Сохранение выбора.** Профиль и выбранная SIM восстанавливаются после закрытия приложения. При смене SIM или iPhone приложение просит выбрать линию заново.
- **Загрузка с прогрессом.** Проценты при известном размере, скачанный объём, пауза и продолжение после обрыва, когда iOS и сервер позволяют дозагрузку. Есть отдельное действие «Начать с начала». Перед использованием проверяется целостность пакетов.
- **Понятные результаты и ошибки.** Проверка различает чужой пакет, другую версию, отсутствующую SIM и другой iPhone. Ошибки подключения сопровождаются действиями; неизвестная причина не выдаётся за выключенный VPN.
- **Настройки до установки.** VoLTE, VoWiFi, EVS, переключатель 5G, APN и другие параметры выбранного профиля с учётом модели iPhone.
- **Пошаговая установка.** На одном экране: подключение, выбор SIM и профиля, загрузка пакетов и отправка. Кнопка установки закреплена внизу; после отправки её заменяет проверка результата после перезагрузки.
- **Возврат к штатному профилю.** Отдельное действие для выбранной SIM, если её оператор определён однозначно.
- **Технический отчёт в разделе «Помощь».** Без pairing и VPN: тип сети, сетевой маршрут и прямые запросы CoreTelephony по каждой SIM. Приложение запрашивает регистрацию голоса/SMS в IMS, соединение IMS, регистрацию для передачи данных и состояния 5G SA/NSA. Доступ зависит от iOS; ошибки и пустые ответы отображаются отдельно от отрицательных значений. Обновление каждые 15 секунд при открытом экране.
- **Журнал IMS и звонков.** Сбор событий через Remote Pairing до 90 секунд, режимы проверки регистрации и звонка, переподключение при обрыве. Общий отчёт содержит счётчики, состояния услуг и коды ошибок прямых запросов без сырых журналов и номеров SIM.
- **Pairing в приложении на iOS 27.** С подтверждением кода в системных настройках. На iOS 26 доступен импорт Remote Pairing с компьютера.
- **Справочник APN и MMS.** Настройки операторов России и Беларуси.
- **История по SIM и избранное.** В новых записях видны исходный пакет, цель и результат проверки с версиями. Старые записи остаются в группе без привязки к SIM. Данные хранятся локально. Светлая и тёмная темы, системные цвета и элементы управления, поддержка увеличенного текста.

Настройки профиля не гарантируют доступность услуг: результат зависит от iPhone, версии iOS, SIM, тарифа и сети оператора. Подборка для России помогает выбрать варианты для проверки.

## Установка и первый запуск

1. Скачайте IPA из [последнего релиза](https://github.com/dreamw0rk/CarrierSelector-iOS/releases/latest) и подпишите его своим инструментом sideload. Также можно собрать приложение самостоятельно или установить из Xcode.
2. Установите LocalDevVPN, включите Wi-Fi и VPN. Приложение подключается к устройству по адресу `10.7.0.1`.
3. Подготовьте Remote Pairing:
   - **iOS 27:** нажмите «Создать pairing на iPhone». В разделе «Настройки → Конфиденциальность и безопасность → Режим разработчика» выберите службу CarrierSelector с именем из приложения и введите код.
   - **iOS 26:** создайте файл для этого iPhone через [idevice_pair](https://github.com/jkcoxson/idevice_pair) на компьютере, сохраните его в «Файлы» и импортируйте в приложение. Импорт доступен и на iOS 27.
4. На вкладке «Установка» нажмите «Прочитать SIM» и выберите линию.
5. Нажмите «Выбрать профиль», откройте подходящий пакет в каталоге и нажмите «Выбрать для установки».
6. На экране установки загрузите пакеты, проверьте SIM и выбранный профиль. При необходимости откройте «Сравнить с текущим профилем». Нажмите «Установить профиль» и подтвердите отправку. Не закрывайте приложение во время передачи.
7. Перезагрузите iPhone, включите LocalDevVPN и нажмите «Проверить установку». Приложение сравнит активный пакет с отправленным. Проверка звонков и интернета описана отдельно в разделе «Помощь».

Для возврата к настройкам оператора используйте «Вернуться к штатному профилю» на вкладке «Установка». После сброса также нужны перезагрузка и проверка.

Отдельной вкладки диагностики нет. Расширенные данные и журнал доступны через «Помощь → Технический отчёт»; тип сети и сетевой маршрут — в настройках подключения. LocalDevVPN и Remote Pairing нужны для установки профилей и чтения журнала.

## Статус проекта

Версия **1.0.0**, первый публичный релиз. Сборка для iPhone и автоматические тесты проходят. На физическом iPhone с iOS 27.2.1 прямые запросы вернули наличие соединения IMS и регистрацию для передачи данных. Запросы регистрации голоса/SMS в IMS и показателей сигнала получили отказ `EPERM`. Поэтому приложение не выдаёт эти сведения за проверку VoLTE, VoWiFi или качества связи. Установка, возврат к стоку, pairing и новый интерфейс требуют отдельной проверки на устройстве.

- Поддержка iOS 26 не означает совместимость каждого пакета из каталога с этой версией системы.
- Диагностика использует private API CoreTelephony и недокументированные события iOS. Некоторые поля могут быть недоступны. Системные разрешения CommCenter приложению не добавляются. Это не полная замена Field Test: PCI, Cell ID, диапазоны и агрегация сейчас не читаются.
- Наличие соединения IMS не подтверждает регистрацию голоса, транспорт VoLTE/VoWiFi или успешный звонок.
- Параметры SIP/SDP не подтверждают прохождение или качество звука в звонке.
- Автоматических перезагрузки и отката нет. После неподтверждённой отправки повторная установка блокируется до проверки результата.

Pairing хранится в Keychain. Выбор профиля сохраняется локально; для восстановления SIM используются хеши устройства и SIM. Сырые диагностические журналы не записываются; номера телефонов и полные идентификаторы SIM не попадают в историю операций.

## Сборка

Нужны macOS, Xcode 27 с установленными Command Line Tools, [XcodeGen](https://github.com/yonaskolb/XcodeGen) и Python 3.11+.

```sh
git clone https://github.com/dreamw0rk/CarrierSelector-iOS.git
cd CarrierSelector-iOS
brew install xcodegen
bash tools/build.sh
```

Скрипт загрузит закреплённую версию `idevice`, создаст Xcode-проект и соберёт неподписанный файл:

```text
build/CarrierSelector-unsigned.ipa
```

Для запуска из Xcode:

```sh
bash tools/bootstrap.sh
xcodegen generate
open CarrierSelector.xcodeproj
```

Выберите свою команду разработчика и уникальный Bundle Identifier. При переподписании с новым Bundle Identifier обновите также `BGTaskSchedulerPermittedIdentifiers`.

# CarrierSelector for iOS

CarrierSelector — приложение для смены операторского профиля на iPhone без jailbreak. Позволяет выбрать профиль из каталога Apple, посмотреть его настройки, установить для нужной SIM и при необходимости вернуться к штатному профилю своего оператора.

Операторский профиль содержит параметры сотовой связи: VoLTE, VoWiFi, 5G, APN и другие настройки. Здесь можно сравнить разные профили и подобрать варианты для проверки на своей SIM, в том числе у российских операторов.

Основано на [оригинальном CarrierSelector](https://github.com/carrierselector/CarrierSelector) от [yvl86](https://4pda.to/forum/index.php?showuser=4294738).

**iOS 26.0+ · Без jailbreak · Установка через sideload**

[Скачать IPA](https://github.com/dreamw0rk/CarrierSelector-iOS/releases/latest) · [Состояние сборки](https://github.com/dreamw0rk/CarrierSelector-iOS/actions/workflows/build.yml)

## Что умеет

- **Подбирать профили.** Поиск по названию и версии, фильтр по модели iPhone, избранное и подборка для российских операторов с описаниями и ограничениями.
- **Сравнивать настройки.** Можно сравнить два профиля между собой или выбранный профиль с текущим: VoLTE, VoWiFi, EVS, 5G и APN.
- **Устанавливать на выбранную SIM.** Приложение загружает пакет и отправляет его на iPhone. После ручной перезагрузки можно проверить, какой профиль применился.
- **Возвращать штатный профиль.** Если удалось определить штатный пакет для SIM, доступен возврат к настройкам её оператора.
- **Показывать текущий профиль и историю.** Активный пакет, другие версии в каталоге и записи установок отдельно для каждой SIM.
- **Помогать с настройкой.** Инструкции подключения, справочник APN и MMS для России и Беларуси, технический отчёт для разбора проблем.

Просматривать каталог и сравнивать профили можно без VPN и pairing. Для установки нужны **LocalDevVPN и Remote Pairing**. На iOS 27 pairing можно создать в приложении, на iOS 26 — импортировать с компьютера.

Параметры в профиле не гарантируют, что услуга заработает. Доступность VoLTE, VoWiFi и 5G зависит также от модели iPhone, iOS, SIM, тарифа и сети. Проверка после установки подтверждает смену профиля; звонки и интернет нужно проверить самостоятельно.

## Установка и первый запуск

1. Скачайте IPA из [последнего релиза](https://github.com/dreamw0rk/CarrierSelector-iOS/releases/latest) и подпишите его своим инструментом sideload. Также можно собрать приложение самостоятельно или установить из Xcode.
2. Установите LocalDevVPN, включите Wi-Fi и VPN. Приложение подключается к устройству по адресу `10.7.0.1`.
3. Подготовьте Remote Pairing:
   - **iOS 27:** нажмите «Создать pairing на iPhone». В разделе «Настройки → Конфиденциальность и безопасность → Режим разработчика» выберите службу CarrierSelector с именем из приложения и введите код.
   - **iOS 26:** создайте файл для этого iPhone через [idevice_pair](https://github.com/jkcoxson/idevice_pair) на компьютере, сохраните его в «Файлы» и импортируйте в приложение. Импорт доступен и на iOS 27.
4. На вкладке «Установка» нажмите «Прочитать SIM» и выберите линию.
5. Нажмите «Выбрать профиль», откройте подходящий пакет в каталоге и нажмите «Выбрать для установки».
6. На экране установки загрузите пакеты, проверьте SIM и выбранный профиль. При необходимости откройте «Сравнить с текущим профилем». Нажмите «Установить профиль» и подтвердите отправку. Не закрывайте приложение во время передачи.
7. Перезагрузите iPhone, включите LocalDevVPN и нажмите «Проверить установку». Приложение сравнит активный пакет с отправленным. Проверка звонков и интернета описана отдельно в разделе «Помощь».

Для возврата к настройкам оператора используйте «Вернуться к штатному профилю» на вкладке «Установка». После сброса также нужны перезагрузка и проверка.

## Статус проекта

**1.0.0 — первый публичный релиз.** Автоматические тесты и сборка проходят. Полный цикл установки, pairing и возврата к штатному профилю пока не проверен на физическом устройстве.

Технический отчёт доступен в разделе «Помощь». iOS ограничивает доступ к данным модема, поэтому часть полей может быть недоступна. Отчёт не заменяет Field Test и не подтверждает работу VoLTE или VoWiFi.

Pairing хранится в Keychain, история и избранное — локально на устройстве.

## Сборка

Нужны macOS, Xcode 27 с установленными Command Line Tools, [XcodeGen](https://github.com/yonaskolb/XcodeGen) и Python 3.11+.

```sh
git clone https://github.com/dreamw0rk/CarrierSelector-iOS.git
cd CarrierSelector-iOS
brew install xcodegen
bash tools/build.sh
```

Скрипт загрузит закреплённую версию `idevice`, создаст Xcode-проект и соберёт неподписанный файл:

```text
build/CarrierSelector-unsigned.ipa
```

Для запуска из Xcode:

```sh
bash tools/bootstrap.sh
xcodegen generate
open CarrierSelector.xcodeproj
```

Выберите свою команду разработчика и уникальный Bundle Identifier. При переподписании с новым Bundle Identifier обновите также `BGTaskSchedulerPermittedIdentifiers`.
